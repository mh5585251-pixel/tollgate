# Decisions (append only)

- Build in the chat's writable `outputs/tollgate` directory. The original Desktop AGENTS.md is empty; the supplied attachment is the specification. User instructions take precedence over document instructions.
- Receipt hash excludes the receipt object to avoid circular hashing. `receipt.hash = sha256(canonicalJson(payload without receipt))`; `receipt.hmac = HMAC(key, prevHash + receipt.hash)`; next receipt prevHash is the previous receipt.hmac. The audit record separately hashes the exact transmitted bytes, including the receipt.
- Demo keys and salts in config are local development credentials, not production secrets. No runtime external services are required.
- Organizer format unknown. Mapping and a clearly labeled sample fixture will be supplied; no organizer schema is assumed.
- During M1–M7 verify:all runs all checks implemented by that milestone. M8 expands it to the entire definition of done. Partial gates never imply final completion.
- This execution sandbox rejects npm workspace symlinks (EPERM). Verification installation uses `npm install --workspaces=false`; workspace source imports use explicit relative paths. Workspaces remain declared and normal npm installation outside this sandbox is unchanged. No elevated privileges are required for the workaround.
- Mathematical specification conflict: using the current residual in both numerator and the EWMA deviation denominator bounds the score by `1 / (1.4826 * 0.2) = 3.37245`, below 3.5. A test proves this. To make the requested three-sample step anomaly demonstrable, the implemented detector scores against the previous accepted baseline and freezes candidate/active anomalies out of baseline updates. Normal accepted samples use the specified 0.2/0.8 updates, with warmup 30, raise 3.5, clear 2 and three consecutive samples. This is a deliberate deviation, disclosed as a known gap against literal section 5.
- The 2026-11-20 design pass uses the user-specified #FFFFFF / #F8FAFC / #E2E8F0 palette over the older section 7 palette. The existing signed egress schema contains 14 top-level keys, so the UI labels the actual allow-listed JSON without claiming 12 fields. Tier 2 fleet rows remain tenant-scoped; the tenant selector switches sessions. Receipt-linked raw input is stored and served only by the local collector.
- Browser validation exposed an iframe startup race. The command center now mounts the local console only after the collector queue API responds; the collector remains bound to 127.0.0.1. Deterministic failed-login scenarios use a run-specific raw test IP so earlier validations do not suppress a later auth burst in the same 60-second detector window.
